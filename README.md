# 🛡️ ForensicsDetector — Professional Photo Forensics & AI Detection Suite

**ForensicsDetector** — это мощное кроссплатформенное C# (.NET) приложение для глубокого криминалистического анализа изображений (Digital Image Forensics). Программа объединяет 16 математических и спектральных модулей анализа для детекции следов фотомонтажа, ретуши, вклейки (Splicing), клонирования (Copy-Move), а также определения изображений, сгенерированных ИИ (Midjourney, Stable Diffusion, DALL-E, Flux и др.).

---

## 🌟 Ключевые особенности

* **16-этапный пайплайн анализа:** Спектральный, математический, метатекстовый и статистический анализ каждого пикселя.
* **Двойной режим работы:** 
  * 🖥️ **Console CLI** — консольный интерфейс с локальным просмотром отчетов.
  * 🤖 **Telegram Bot** — встроенный Telegram-бот с поддержкой очереди и отправки полного HTML-отчета документом.
* **Интерактивные HTML-отчеты:** Автоматическая генерация изолированного HTML-файла со всеми визуальными картами (ELA, 2D FFT, Noise Map, Copy-Move, JPEG Ghosts).
* **Детекция C2PA:** Распознавание цифровых криптографических подписей искусственного интеллекта и редакторов (Content Credentials).
* **Двуязычный интерфейс:** Полная поддержка русского и английского языков (RU / EN).

## 🔬 16 Этапов анализа (Forensic Pipeline)

1. **EXIF / XMP & Signatures:** Анализ метаданных, поиск сигнатур графических редакторов (Photoshop, GIMP, PicsArt).
2. **C2PA Credentials:** Проверка криптографических меток происхождения (Adobe Content Credentials / JUMB).
3. **Liquify & Retouching:** Детекция локального сглаживания, пластики и ретуши по контрасту и вариативности.
4. **Double JPEG Quantization (DQ):** Выявление повторного сохранения файла с помощью анализа эффектов гребенки DCT.
5. **Error Level Analysis (ELA):** Карта ошибок сжатия JPEG с поиском локальных пиков разницы.
6. **High-Pass Noise Map:** Извлечение высокочастотного шума матрицы и выявление "стерильных" участков.
7. **Copy-Move Clone Stamp:** Векторная кластеризация ключевых точек (ORB + Hamming BFMatcher) для детекции штампа.
8. **JPEG Ghosts (Q75 & Q85):** Вычисление призраков повторного сжатия при разном качестве.
9. **Noise Mismatch Analysis:** Оценка дисперсии шума по градиентам Sobel (поиск локальных вклеек).
10. **2D FFT Fourier Spectrum:** Анализ спектра Фурье для выявления артефактов Latent VAE и апскейлеров ИИ.
11. **Bayer CFA Demosaicing:** Оценка целостности структуры цветного фильтра Байера (Bayer Pattern).
12. **PRNU Fingerprint Analysis:** Оценка отпечатка физического сенсора камеры (Photo-Response Non-Uniformity).
13. **Y/CbCr SNR Mismatch:** Сравнение соотношения сигнал/шум каналов яркости и цветности.
14. **SRM (Spatial Rich Models):** Анализ остатков фильтрации 3-го порядка.
15. **Chromatic Aberrations (CA):** Проверка наличия естественных фазовых хроматических аберраций объектива.
16. **Upscaler Checkerboard:** Поиск сетчатых артефактов нейросетевых апскейлеров.

## 🚀 Быстрый запуск

### Требования
* **.NET 8.0 SDK** или выше
* Поддерживаемые ОС: Windows, Linux, macOS

### Установка зависимостей (NuGet)
Проект использует следующие библиотеки:
```bash
dotnet add package OpenCvSharp4
dotnet add package OpenCvSharp4.official.win # или runtime для вашей ОС
dotnet add package SixLabors.ImageSharp
dotnet add package MetadataExtractor
```

### Сборка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/ForensicsDetector.git
   cd ForensicsDetector
   ```
2. Запустите проект:
   ```bash
   dotnet run
   ```
3. Или передайте путь к изображению напрямую через аргумент:
   ```bash
   dotnet run -- "C:\images\sample.jpg"
   ```

## 🤖 Настройка Telegram Бота

1. Запустите программу и выберите режим `2. Запустить Telegram Бота`.
2. Введите токен, полученный от [@BotFather](https://t.me/BotFather).
3. Токен сохранится в `config.json`.
4. Отправляйте боту фотографии или файлы (для сохранения EXIF рекомендуем отправлять как **Файл/Документ**).

## 📊 Пример отчета (HTML Report)

После каждого анализа программа создаёт автономный HTML-файл `Forensics_Report_YYYYMMDD_HHMMSS.html`, содержащий:
* Итоговые вердикты и шкалы вероятности фотошопа и ИИ.
* Галерею визуальных карт (2D FFT, ELA, High-Pass, Copy-Move, JPEG Ghosts Q75/Q85, Bayer CFA).
* Полную структурированную таблицу EXIF/XMP метаданных.
